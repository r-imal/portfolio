# Rimal Banik Portfolio

Simple static portfolio for showcasing education, projects, research interests, experience, CV, and contact information.

## Notes

1. Replace the initials block in `index.html` with a real profile photo when available.
   - Add your image as `assets/profile.jpg`.
   - Replace the `.profile-photo` `<div>` with:

```html
<img class="profile-photo" src="assets/profile.jpg" alt="Rimal Banik">
```

2. The site is designed to be hosted from the repository root using GitHub Pages.
