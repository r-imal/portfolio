# Rimal Banik Portfolio

Simple static portfolio prepared for the Data Edge Limited Trainee Software Engineer application.

## Update Before Publishing

1. Replace the initials block in `index.html` with a real profile photo when available.
   - Add your image as `assets/profile.jpg`.
   - Replace the `.profile-photo` `<div>` with:

```html
<img class="profile-photo" src="assets/profile.jpg" alt="Rimal Banik">
```

2. Publish with GitHub Pages:
   - Create a new GitHub repository, for example `rimal-portfolio`.
   - Upload everything inside this `portfolio-site` folder.
   - Go to repository `Settings` > `Pages`.
   - Select `Deploy from a branch`, choose `main`, folder `/root`, then save.
   - Your public link will look like `https://fuad7181.github.io/rimal-portfolio/`.

3. After the GitHub Pages link is active, add it to the CV if you want a final polished CV link.
